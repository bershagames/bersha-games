For help with Block Merge Rush, email bershagames@gmail.com.

  • Game name

  • Android version
  • A description of the problem
  • Steps that caused the issue
  • Screenshots, if available

Do not include passwords, financial credentials, government IDs, or other sensitive information in support emails.

  • Save or progress issues
