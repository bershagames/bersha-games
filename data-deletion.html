Block Merge Rush — Data Deletion

Block Merge Rush currently does not use user accounts or BERSHA GAMES cloud storage. Game data is stored locally on the device.

Method 1 — In the game

Open Block Merge Rush, go to Settings, and use the Reset/Delete local data option where available.

Method 2 — Android settings

Open Android Settings → Apps → Block Merge Rush → Storage, then choose Clear Data or Clear Storage. Exact labels may vary by device.

Method 3 — Uninstall

Uninstall Block Merge Rush from the device. Android backup settings may affect whether some app data can later be restored.

Because the current version does not transmit game data to BERSHA GAMES servers, there is currently no server-side player account record for BERSHA GAMES to delete.
